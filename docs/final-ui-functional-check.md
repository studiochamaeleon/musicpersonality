# MUTI 최종 UI·기능 보완 — 2026-10-05

기존 강한 타이포, 장르별 결과 색상, 도트 배경, 공유 카드 스타일을 유지했다. 이번 작업은 조작 안정성과 정보 가독성을 보완했으며 문항, 점수 계산, 결과 버전, 추천 순위, 음악 카탈로그는 변경하지 않았다. 새 계정·DB·외부 API는 추가하지 않았다.

## 반영한 사항

- 공유: 같은 이벤트 턴의 두 번 클릭이 `navigator.share`를 두 번 호출하는 현상을 재현했다. 즉시 잠금과 처리 상태를 제공하며 공유·복사·이미지 캡처 중 중복 요청을 막았다. 파일 공유 취소, 생성 실패, 전달 실패, 직접 저장의 기존 복구 경로를 유지했다. 다운로드 완료와 공유 시트를 구분하여 안내한다.
- 설문: 방향키로 라디오를 탐색할 때 550ms 후 자동 제출되던 동작을 수정했다. 방향키는 선택만 변경하고 Enter·Space·다음 버튼으로 확정한다. 클릭·숫자 키 자동 진행은 유지하며 질문과 응답 그룹을 접근성 이름으로 연결했다.
- 개인 결과·궁합: 섹션 바로가기와 펼침 영역을 44px 이상으로 정리했다. 취향·사운드 막대에 읽을 수 있는 값과 이름을 제공했다. 궁합 추천곡에도 앨범·녹음 크레딧을 표시하며 곡 교체를 아티스트·곡명으로 안내한다.
- 피드백: 복사를 단일 실행하고 대기 중 상태를 표시한다. 복사 중 초안·곡·언어가 달라지면 이전 보고서의 완료 안내를 새 보고서에 붙이지 않는다.
- 홈·탐색: 언어 버튼과 저장 이력 펼침의 터치 영역을 확장했다. 검색어 지우기·필터 초기화 후 입력 초점을 유지한다. 삭제 성공·저장소 거절을 구별하며 삭제 후 남은 결과나 검사 버튼으로 초점을 돌린다.
- 배경: 장르 탐색의 기존 고정 캔버스는 유지한다. 홈에서 저장 이력을 펼쳐 페이지가 길어져도 화면 크기의 캔버스만 그린다. 숨겨진 탭에서는 애니메이션을 중지하며 실행 중 모션 감소 설정 변경과 화면 회전을 반영한다.
- 레이더 차트: 320px 화면에서 영어 축명이 SVG 밖으로 잘리는 것을 좌표로 확인했다. 좁은 영역의 반경·축 글자를 조절하고 전체 이름과 점수를 두 열 범례로 표시한다. `animated=false`와 모션 감소가 실제 레이더 도형에도 적용되도록 정리했다.

## 검증 범위

- 최종 프로덕션 빌드, ESLint, TypeScript `--noEmit`, `git diff --check` 통과.
- 단위 테스트 **96/96** 통과. 카탈로그 무결성 **34개 장르·88개 앨범·88개 곡** 통과.
- 레이더 차트 마지막 보완 전 모바일 Chromium 전체 회귀 **175/175** 통과.
- 차트 보완을 포함한 최종 빌드에서 개인 결과·장르 상세·언어·모바일 가독성·본문 완전성 Chromium 회귀 **33/33** 통과.
- 같은 최종 빌드에서 공유·설문 키보드·궁합 정보·홈 이력·도트 모션·차트·바이럴 흐름 WebKit 회귀 **47/47** 통과.
- 320px 홈·개인 결과·궁합·탐색·장르 대화상자와 최종 영어 레이더 차트를 캡처해 시각 확인했다.

홈 배경 테스트는 배경 바깥의 공통 법적 고지 푸터를 제외한 `main` 영역 안에서 검증한다. 공유 고정 버튼 테스트는 화면 렌더링을 기다린 뒤 스크롤하도록 정리하여, Safari의 로딩 중 스크롤 초기화를 UI 오류로 오인하지 않도록 했다.

Playwright WebKit은 Safari 계열 렌더링과 공유 파일·취소 동작의 모의 검증이며 실제 iPhone 공유 시트나 Instagram 게시를 보증하지 않는다. 실제 음악 선호나 심리측정 정확도 검증과도 다르다.

실기기 확인 항목은 [iPhone 점검표](ios-smoke-checklist.md)에 정리했다. 기존 작업을 보존했으며 커밋·새 브랜치·푸시·배포는 하지 않았다.
