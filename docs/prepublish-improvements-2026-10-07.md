# MUTI 퍼블리시 전 보완 기록 — 2026-10-07

이 문서는 2026-10-05 검수에서 권장한 변경의 구현 기록이다. 기존 검수 기록을 대체하지 않는다. 검수 완료 당시에는 로컬 변경 상태였고 커밋·푸시·배포는 하지 않았다. 이후 배포는 사용자의 별도 승인을 받아 진행한다.

## 구현한 보완

### 1. 단일 장르로 과하게 단정하지 않는 결과

다섯 취향 점수와 기존 장르 순위로 다음 안내를 구분한다.

| 상태 | 안내 기준 |
| --- | --- |
| 탐색용 추천 | 가장 가까운 장르 유사도가 60 미만이거나 장르가 없음 |
| 중간에 가까운 취향 | 다섯 점수 차이가 10 이하이고 모두 45–55 범위 |
| 폭넓게 열린 취향 | 다섯 점수 차이가 10 이하이고 모두 65 이상 |
| 고르게 나타난 취향 | 위에 해당하지 않지만 다섯 점수 차이가 10 이하 |
| 가까운 장르 중 하나 | 상위 두 장르의 반올림 전 유사도 차이가 3%p 이하 |
| 기존 결과 표현 | 위에 해당하지 않음 |

위 순서로 적용한다. 예를 들어 모든 축이 0이면 고른 취향보다 탐색용 추천 안내가 우선이다. 이 기준은 이해를 돕는 **편집 기준**이며, 심리측정 신뢰도나 응답 성실도 판정이 아니다. 점수만으로 실제 원응답 패턴을 추정하지 않는다.

- resultInterpretation.ts를 결과 화면과 Cloudflare 개인 공유 미리보기에서 함께 사용한다.
- 탐색 안내가 필요한 결과는 강한 장르·캐릭터 타이포를 유지하면서 “지금 탐색할 음악은”으로 소개한다. “이 음악을 사랑한다”는 단정을 피한다.
- 결과에는 자세한 설명, 이미지 카드에는 같은 의미의 짧은 설명, OG 이미지에는 동일한 상태 배지와 탐색 추천 표시를 넣는다.
- 공유 텍스트·OG 제목/설명에도 안내를 반영한다.
- 점수·대표 장르·장르 순위를 바꾸거나 결과를 무효 처리하지 않는다.

### 2. 문항 의미와 번역 정합성

- 강렬함 2·3·4·7은 감정·가사·극적인 분위기 대신 거친 질감, 몰아치는 리듬, 에너지 전환 등 들리는 사운드를 묻도록 바꿨다.
- 강렬함 6도 빠르고 몰아치는 리듬에 대한 신체 반응을 묻는다.

- 차분함 5·6, 편안함 1·5, 탐구성 8의 감상 행동/선호 표현을 세 언어에서 맞췄다.
- 현대적 사운드 6에 전자 비트·샘플 소리를 명시해, 반복 전개만으로 미니멀리즘을 현대적 사운드로 읽는 혼선을 줄였다.
- 40문항·각 축 8문항·문항 ID·5점 척도·가중치·역채점 설정은 유지했다.

### 3. 이전 결과와 설문 버전

- 설문 버전은 2에서 3으로 올렸다. 이전 미완료 답변을 새 문항과 섞어 이어서 검사하지 않는다.
- 결과 계산 버전은 바꾸지 않았다. 기존 v2/v3 링크는 각각 기존 점수·장르 순위로 복원한다.
- 설문 v2 저장 행에 명시적 결과 버전이 없는 경우에도 기존 결과 계산 v3으로 복원한다. 설문 개정 때문에 결과가 v2로 잘못 돌아가지 않는다.
- 친구 궁합에 검사 시기에 따른 문항 표현 차이가 있을 수 있음을 안내한다. 비교 대상은 저장된 다섯 취향 점수다.
- 새 개인 공유 URL의 pv와 OG 이미지의 ogv는 3으로 올렸다. 예전 링크의 파라미터는 계속 허용하며, 새 공유의 미리보기 캐시를 구분한다. 이미 SNS에 캐시된 이전 게시물의 이미지까지 강제로 갱신하지는 못한다.

### 4. 문구와 모바일 카드

- 한국어 결과 요약의 받침에 맞춰 “과/와”를 선택한다.
- 장르 탐색의 bridge 배지를 한국어·일본어에서 실제 앨범 링크와 맞췄다.
- 320px 카드에서 제작자명을 별도 줄에 두어 영문명이 쪼개지지 않게 했다.
- 해석 안내가 추가된 카드의 높이는 내용에 맞게 늘어나며 경고·푸터를 잘라내지 않는다.
- 도트·색상·타이포 및 기존 결과의 상세 해석 기본 펼침은 유지했다.
