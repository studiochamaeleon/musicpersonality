## 구성과 노출 원칙

- 81개 장르별 추천과 7개 교차 추천, 총 88개 곡·앨범 링크를 관리한다. 장르별 추천은 2–4개 이내이며 이번 카탈로그는 2–3개다.
- 기존에 현대 발견곡이 없던 장르와 메인스트림 팝에 총 13개 발견곡을 추가했다. 34개 장르 모두 2020년대 발매·녹음의 discovery를 최소 하나 갖는다.
- 개인 결과에는 대표 입문곡 하나 + 상위 세 장르에서 발견곡 하나씩 + 해당하는 경우 교차 추천 하나를 보여준다. 결과에는 최대 6개, 현재 일반적인 구성은 4–5개 슬롯만 표시해 한 번에 과도한 목록을 만들지 않는다.
- 현대 발견곡을 기본으로 노출하고, 기존 명곡은 ‘같은 장르의 다른 곡’으로 선택한다. 교차 추천은 ‘다른 장면의 곡’으로 순환하며 카탈로그 앞부분에 있는 아티스트가 뒤의 아티스트를 가리지 않는다.
- 대표곡은 고정한다. 선택은 현재 화면에만 적용되고 점수·타입·URL·저장된 결과를 바꾸지 않는다. 재진입하면 동일한 기본 추천으로 복원한다. 현재 보이는 곡이 피드백 보고서에도 반영된다.

2. `node scripts/audit-spotify-tracks.mjs --mismatches`: 공개 Spotify 앨범 임베드에서 실제 트랙 ID의 수록 여부와 곡 제목·앨범 판본 제목·아티스트 크레딧을 대조한다. 협업곡은 이름에 명시된 아티스트가 모두 크레딧에 있어야 한다. 일본어 발음 구분은 유지하고 라틴 문자 악센트·문장부호 차이만 정규화한다.
3. 외부 검사 중 429·502·503·504와 네트워크 장애는 두 번까지만 재시도한다. 그래도 실패하거나 매핑이 틀리면 성공으로 처리하지 않고 종료 코드 1을 반환한다. 앱 사용 중 Spotify API를 호출하지 않는다.
4. 단위 테스트는 실제 34개 프로필의 상위 장르 결과에서도 현대 발견곡이 기본 노출되는지, 모든 기존 대안·교차 아티스트에 접근할 수 있는지, 중복 방지·대표곡 고정·기본 추천의 재현성을 확인한다.
5. 모바일 E2E는 한·영·일 320px 화면의 교체 버튼, 키보드 초점, 피드백 반영, URL·타입 유지와 새로고침 복원을 확인한다.

확인한 정보는 해당 시점의 수록·메타데이터다. 국가·계정별 재생 권한, 아티스트의 모든 음악의 장르 분류, 사용자의 실제 선호와 향후 Spotify 삭제·변경을 보증하지 않는다.
