# MUTI 소규모 사용자 점검

목적은 사용상의 막힘과 음악 추천의 구체적인 불일치를 찾는 것이다. 소규모 사용자 의견만으로 심리측정학적 타당도나 성격 예측 정확도를 주장하지 않는다.

## 진행 방법

1. 평소 좋아하는 곡 2개를 먼저 적어두고 검사를 진행한다. 결과를 본 뒤 곡을 고르면 회상 편향이 생길 수 있다. 이름·연락처는 필요 없다.
2. 이해하기 어렵거나 비슷해 보이는 질문의 문항 번호와 해석한 의미만 기록한다. ‘큰 볼륨’과 ‘소리의 밀도’를 혼동했는지 확인한다.
3. 결과 장르, 음악 캐릭터 설명, 추천곡을 별도로 평가한다. ‘성격이 맞아서 음악도 맞다고 느꼈다’는 응답과 실제 선호를 구분한다.
4. 대표곡에서 친숙함을, 발견곡에서 새로운 관심을 느꼈는지 묻는다. 발매 연도가 오래됐다는 의견과 실제로 취향에 안 맞았다는 의견도 구분한다.
5. 친구 초대를 보내고 받은 사람이 저장 결과를 연결한다. 재검사가 필요한 줄 알았는지, 공유와 초대를 혼동했는지, 사용할 결과의 장르가 잘 보였는지 확인한다.
6. 궁합의 축별 공통점·차이점과 세 추천곡의 역할을 본인 말로 설명하도록 부탁한다. 점수를 관계의 성공 확률이나 곡 선호 확률로 이해했다면 문구 개선 대상으로 기록한다.
7. 다른 곡을 선택한 뒤 어떤 곡이 더 가까웠는지 구체적으로 묻는다. 곡 교체로 검사 점수도 바뀐다고 생각하지 않았는지 확인한다.
8. 개인·궁합 공유 메뉴에서 원하는 결과를 메시지와 스토리에 보내도록 한다. 실제 기기, OS 버전, 사용 앱, 선택한 메뉴, 막힌 단계를 기록한다. 자동 테스트가 실제 공유 앱의 통합을 보증하지는 않는다.

## 전달 내용

서비스의 접힌 ‘결과가 어땠나요?’ 입력란을 사용하면 장르·버전·추천곡과 항목별 평가를 미리 보고 복사할 수 있다. 입력은 기기에 영구 저장하거나 자동 수집하지 않는다. 복사만으로 운영자에게 전송되지는 않으므로 참여자가 동의한 전달 경로로 별도 전달한다. 공유 URL과 원점수, 개인 식별 정보는 공개 이슈에 올리지 않는다.

## 개선 판단

- 장르는 맞고 특정 곡만 어긋남: 곡 큐레이션을 먼저 검토한다.
- 곡은 맞는데 장르명에 낯섦: 장르의 짧은 사운드 설명과 명칭을 먼저 검토한다.
- 특정 질문의 의미를 반복해서 다르게 이해함: 문구를 검토하고 문항 버전·구버전 복원 영향도 확인한다.
- 캐릭터 문구만 어긋남: 해당 문구를 수정하며 추천 점수식까지 자동으로 바꾸지 않는다.
- 궁합·공유의 버튼을 못 찾음: 행동 우선순위와 안내 문구를 수정한다.
- 임의로 퍼센트를 올리거나 질문 수를 늘려 해결하지 않는다. 더 큰 표본의 검증이 필요하면 수집 범위·동의·저장 방법을 먼저 별도로 결정한다.
