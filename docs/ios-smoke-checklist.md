# iPhone Safari 출시 전 점검표

Playwright WebKit은 iPhone 화면 크기와 렌더링·자바스크립트 흐름을 검증하지만, iOS 공유 시트와 Instagram 설치 상태를 재현하지는 못한다. 아래는 실제 iPhone의 Safari에서 한 번씩 확인할 항목이다.

1. 새 검사 완료: 한국어·영어·일본어 각각에서 결과 본문, 세 곡짜리 친구 궁합 추천, Spotify 곡 링크가 화면 폭을 넘지 않는지 확인한다.
2. 개인 결과의 **이미지 저장**: iOS 공유 시트가 열리고 `muti-result.png` 이미지 파일이 전달되는지, **이미지 저장**을 고르면 사진 앱에서 읽히는지 확인한다.
3. **스토리용 카드 공유**: 공유 시트에서 Instagram Stories를 선택할 수 있는 설치 환경이면 9:16 이미지가 열리는지 확인한다. Instagram은 웹사이트가 스토리에 자동 게시할 수 없으므로 최종 게시는 사용자가 한다.
4. 친구 궁합 **이미지 저장**: 공유 시트에 `our-music-match.png`가 전달되고 이미지가 잘리지 않는지 확인한다.
5. 개인 `v=3` 결과 링크, 기존 `v=2` 결과 링크, 친구 궁합 링크를 각각 새 Safari 탭과 카카오톡/메시지 앱 내부 브라우저에서 열어 결과와 선택 언어가 복원되는지 확인한다.
6. 저장된 최근 결과가 인트로에 나타나는지, 그 결과에서 친구 궁합 초대로 바로 이어지는지 확인한다. Safari의 비공개 브라우징이나 사이트 데이터 삭제 후에는 로컬 결과가 사라지는 것이 정상이다.
7. 인트로 → 장르 탐색, 인트로 → 검사 중 2문항 응답, 개인 결과 → 궁합 초대 경로에서 Safari 뒤로가기·앞으로가기와 화면 가장자리 스와이프를 확인한다. 검사로 다시 돌아오면 응답과 진행 위치가 유지되어야 한다.
8. 기존 v2 결과로 궁합 링크를 만든 뒤 새 탭에서 열고 개인 결과로 돌아간다. 링크의 `hv=2`/`gv=2`와 개인 결과 `v=2`가 유지되고 장르가 바뀌지 않아야 한다.
9. 궁합의 두 참여자가 ‘초대한 사람 / 응답한 사람’으로 표시되는지, 양쪽 개인 결과 버튼이 정확한 사람을 여는지 확인한다. 공유 이미지에 두 장르와 음악 캐릭터가 모두 잘리지 않고 보여야 한다.
10. 인트로의 최근 궁합을 다시 열고 삭제한다. 궁합 삭제 후 개인 결과 이력이 유지되는지 확인한다. 숫자가 같은 친구의 저장 결과도 검사 없이 비교할 수 있어야 한다.
11. 개인·궁합의 **결과 공유**를 열고 네 가지 전달 방법을 확인한다. 닫기·바깥 영역·키보드 Escape로 닫으면 배경 스크롤이 복원되고 원래 버튼으로 포커스가 돌아가야 한다. 상단·하단 고정 공유 버튼도 같은 메뉴를 열어야 한다.
12. 궁합의 스토리 카드가 `muti-match-story.png`의 1080×1920 이미지로 전달되는지 확인한다. 공유 대상 앱이 보이지 않으면 이미지 저장 후 직접 게시할 수 있는지 확인한다.
13. 초대를 직접 만든 화면에서는 친구에게 보내기가 먼저, 받은 링크에서는 저장 결과가 있을 때 바로 비교하기가 먼저 보여야 한다. 다른 친구와 비교하기에서는 초대에 넣을 참여자를 직접 선택해야 한다.
14. 세 추천곡을 여러 번 교체한다. 서로 중복되지 않고 점수와 참여자 역할이 그대로인지, 다시 링크를 열었을 때 기본 추천으로 복원되는지 확인한다.
15. 피드백을 입력하고 미리보기·복사를 확인한다. 페이지를 다시 열면 입력은 없어져야 하며 자동으로 서버나 이메일에 전송되어서는 안 된다.
16. 공유·이미지 저장을 빠르게 두 번 눌러도 한 작업만 실행되어야 한다. 진행 중에는 처리 상태가 보이고 취소 후 다시 선택할 수 있어야 한다. 브라우저 다운로드로 저장했다면 다운로드 목록 확인 안내가 표시되어야 한다.
17. 외부 키보드가 있다면 방향키로 응답을 천천히 살펴본다. 선택만 바뀌고 다음 문항으로 넘어가지 않아야 하며 Enter·Space로 확정하거나 숫자 키로 답하면 기존 자동 진행이 동작해야 한다.
18. 최근 결과 삭제 후 성공 안내와 남은 결과를 확인한다. 언어 버튼과 다른 저장 결과 펼침이 작은 화면에서도 한 줄로 읽히고 누르기 편해야 한다. 장르 검색을 지우거나 필터를 초기화한 뒤 계속 입력할 수 있어야 한다.

문제가 생기면 기기 모델, iOS 버전, Safari/인앱 브라우저 종류, 사용 언어, 재현 단계와 공유 링크의 `v`/`sv` 값만 기록한다. 링크에는 음악 취향 점수가 담기므로 공개 이슈에 전체 URL을 올리지 않는다.
